ไอแพดติดตั้งไฟล์ .exe ไม่ได้ เวอร์ชันนี้จึงเป็น "เว็บแอป" ที่ติดตั้งลงหน้าจอโฮมของไอแพดได้เหมือนแอป

ขั้นที่ 1 — นำโฟลเดอร์นี้ขึ้นเว็บไซต์ (ทำครั้งเดียว)
  ต้องเป็นเว็บที่ใช้ https:// เช่น GitHub Pages, Cloudflare Pages, Netlify หรือเซิร์ฟเวอร์ของบริษัท
  อัปโหลด "ทุกไฟล์ในโฟลเดอร์นี้" (index.html ต้องอยู่ชั้นบนสุด)
  เซิร์ฟเวอร์ควรส่ง .wasm เป็น application/wasm และ .mjs เป็น text/javascript (โฮสต์ข้างต้นทำให้อัตโนมัติ)

ขั้นที่ 2 — ติดตั้งบนไอแพด
  1. เปิด Safari แล้วไปที่ที่อยู่เว็บจากขั้นที่ 1
  2. แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
  3. เปิดจากไอคอน Pro-2D+3D บนหน้าจอโฮม — เปิดเต็มจอเหมือนแอป และใช้แบบออฟไลน์ได้หลังเปิดครั้งแรก
     (ไฟล์ DWG/IFC/SKP/PDF ต้องเปิดตอนออนไลน์ 1 ครั้งก่อน ระบบจึงจะเก็บไว้ใช้ออฟไลน์)

การใช้งานด้วยนิ้ว
  1 นิ้ว (เครื่องมือเลือก): แตะ = เลือก · ลากชิ้นงาน = ย้าย · ลากที่ว่าง = เลื่อนแบบ
  1 นิ้ว (ผนัง/ประตู/หน้าต่าง/บอกขนาด): เลื่อนนิ้วเพื่อเล็ง → ยกนิ้ว = วางจุด · แตะจุดสุดท้ายซ้ำ = จบผนัง
  2 นิ้ว: จีบ = ซูม · ลาก = เลื่อนแบบ          มุมมอง 3D: 1 นิ้วหมุน · 2 นิ้วซูม/เลื่อน
  แนวตั้ง: แปลน 2D อยู่บน โมเดล 3D อยู่ล่าง · แนวนอน: อยู่ข้างกัน

ไฟล์บนไอแพด
  เปิด: DWG, DXF, IFC, SKP, OBJ, PDF, .p23  (เมนู ไฟล์ → เปิดไฟล์ → เลือกจากแอป "ไฟล์")
  บันทึก: .p23, DXF, IFC4, OBJ, PDF  → หน้าต่างแชร์ → "บันทึกไปยังไฟล์"
  บันทึก DWG ทำได้เฉพาะโปรแกรมเวอร์ชัน Windows — บนไอแพดให้บันทึกเป็น DXF แทน (AutoCAD เปิดได้)

iPads cannot run .exe files. This is the web/PWA edition: host this folder on any HTTPS site,
open it in Safari on the iPad, then Share → "Add to Home Screen". Works offline after the first visit.
