iPad ติดตั้งไฟล์ .exe ไม่ได้ จึงทำเป็น "เว็บแอป" ที่เพิ่มลงหน้าจอโฮมได้เหมือนแอป และใช้งานแบบออฟไลน์ได้
มี 2 โปรแกรมแยกกัน (เหมือนบนคอม):
  Pro3D-2027  ดูโมเดล 3 มิติ  — จอ 3D + รูปด้าน 2 จอ, ตัด section แกน X/Y/Z, วัดระยะ/มุม/พื้นที่, ซ่อน, โปร่งแสง
  Pro2D-2027  อ่านแบบ 2 มิติ — DWG/DXF/PDF, Layer, Layout, หาข้อความ, วัดระยะ/มุม/พื้นที่

ขั้นที่ 1 — นำโฟลเดอร์นี้ขึ้นเว็บ (ทำครั้งเดียว)
  ต้องเป็นเว็บ https:// เช่น GitHub Pages, Cloudflare Pages, Netlify หรือเซิร์ฟเวอร์ของบริษัท
  อัปโหลด "ทุกไฟล์ในโฟลเดอร์นี้" (index.html ต้องอยู่ชั้นบนสุด)

ขั้นที่ 2 — ติดตั้งบน iPad
  1. เปิด Safari ไปที่ที่อยู่เว็บ → แตะการ์ด Pro3D-2027 หรือ Pro2D-2027
  2. แตะปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" (ทำทีละโปรแกรม จะได้ 2 ไอคอน)
  3. เปิดจากไอคอนบนหน้าจอโฮม — เต็มจอเหมือนแอป และใช้ออฟไลน์ได้หลังเปิดครั้งแรก

การใช้นิ้ว
  Pro3D: 1 นิ้วลาก = หมุน · 2 นิ้ว = เลื่อน / ถ่างซูม · แตะ 2 ครั้ง = ดูทั้งหมด
         รูปด้าน: 1 นิ้ว = เลื่อน · 2 นิ้ว = ถ่างซูม · ปุ่ม ↺ ↻ หมุน 90° · "พอดีจอ"
         วัดระยะ/มุม: แตะทีละจุด (ดูดเข้ามุมใกล้นิ้วอัตโนมัติ) · หาพื้นที่: แตะพื้นผิว · ซ่อน: แตะชิ้นงาน
  Pro2D: 1 นิ้ว = เลื่อน · 2 นิ้ว = ถ่างซูม · แตะ 2 ครั้ง = ดูทั้งหมด

ไฟล์ที่เปิดได้ (จากแอป "ไฟล์" / iCloud / AirDrop)
  Pro3D: SKP, IGZ, IFC, OBJ, GLB/glTF, DWG/DXF (แสดงเป็นเส้น)   — DAE ยังไม่รองรับ (ส่งออกเป็น SKP/GLB/OBJ แทน)
  Pro2D: DWG, DXF, PDF
  ไฟล์ใหญ่มาก (DWG เกิน ~30 MB) อาจเปิดช้าหรือหน่วยความจำ iPad ไม่พอ

อัปเดตเวอร์ชัน: เมื่ออัปโหลดไฟล์ใหม่ ให้เปลี่ยน VERSION ใน sw.js ทุกครั้ง iPad จึงจะโหลดของใหม่

Pro2D-2027 / Pro3D-2027 for iPad — web app (PWA). Host this folder on any HTTPS site, open it in
